# Pulse Path

Reconstruction of the visible four-lane rhythm game: falling beat tiles, score and streak multipliers, double-value charge beats, levels, lives, keyboard/touch controls, and browser-local best score. Timing and rendering run locally with no account or network service.

The matching `AWEMISSIONS/Pulse-Path` repository had no usable source. The live game showed the core play loop and this rebuild follows it; timing, visuals, and scoring are a fresh implementation.
